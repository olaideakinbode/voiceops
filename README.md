# VoiceOps

VoiceOps is an enterprise AI operations platform for monitoring, governing, and continuously improving AI voice agents in production.

## Vision

Building AI voice agents is only half the challenge.

VoiceOps provides the operational layer teams need to monitor conversations, investigate failures, govern deployments, and continuously improve AI systems after they go live.

## MVP

- Operations Dashboard
- Conversation Feed & Lifecycle History
- Conversation Workspace
- Human Escalation
- AI Performance Analytics

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Radix UI
